# NEXUMA Consulting Group - Versión Tech Animada

## Qué se cambió

- Hero principal rediseñado con estética tecnológica: grid animado, auroras, partículas, scan line, mundo holográfico, órbitas, nodos y paneles HUD.
- Header más profesional con navegación: Servicios, Método y Contacto.
- Copy principal más directo hacia negocio: Salesforce, IA, automatización, APIs y desarrollo.
- Servicios rediseñados como módulos tecnológicos interactivos.
- Se agregó sección "Digital Command Center" para reforzar imagen de empresa tech.
- Se agregó sección "Método NEXUMA" para explicar cómo trabajan los proyectos.
- Se corrigió el botón duplicado de WhatsApp y se dejó un agente flotante más profesional.
- Se limpió `index.css` para que el sitio use ancho completo y no quede limitado por estilos base de Vite.
- Se mantuvo el selector español/inglés.

## Archivos modificados

- `src/App.jsx`
- `src/App.css`
- `src/index.css`

## Cómo correrlo local

```bash
npm install
npm run dev
```

## Cómo validar build

```bash
npm run build
```

## Cómo subirlo a producción

Después de reemplazar los archivos en tu proyecto local:

```bash
git add .
git commit -m "Mejora visual tech animada para sitio NEXUMA"
git push
```

Si Vercel está conectado a GitHub, se desplegará automáticamente.
